# Jovan Ikić · sajt

Sajt kondicionog trenera Jovana Ikića iz Novog Sada. Običan HTML i CSS, bez biblioteka i bez build koraka.

- `index.html` – početna, posetilac bira cilj
- `jovan-par.html` – Treniramo u paru
- `jovan-sportista.html` – Za sportiste
- `jovan-mrsavljenje.html` – Za mršavljenje
- `slike/jovan.jpg` – fotografija

Dok sajt ne bude gotov, svaka strana ima `noindex` da je pretraživači ne uzimaju. Kad se ubace pravi podaci (Viber i Instagram linkovi, recenzije, Jovanova priča), obriši red `<meta name="robots" ...>` iz svih strana.
